# A6 cards printable template
why buy small papers when you can slice big ones, why use gdocs, msword, or whatever when you have html? been looking for a solution that is easy to replicate, quick to use, and versioning ability. Now it's all possible.
1. Download it, open in your-hundreds of tabs opened-browser
2. type your text
3. you want more pages? hit add page
4. text size too small for 10.5 pt? no problem. adjust the text size with hover-reveal control.
5. "but i love images" gotchu, you can add them.
4. print, then follow the dashed line with scissors

code assisted with AI
